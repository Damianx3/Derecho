# Data

This directory contains data used by DERECHO.

## legal_sources

Trusted immigration-rights documents used by the Know Your Rights retrieval system.

Source documents should include metadata identifying the organization, title, publication date when available, and source location.

## evaluation

Evaluation datasets used to test:

- speech recognition
- translation
- retrieval
- grounded legal responses
- unsupported questions
- latency
- privacy

Large or sensitive datasets should not be committed directly to the repository.
